# 对话教练 · Dialogue Coach（v0.2 冻结版）

一个让 AI 不急着给你答案、而是先帮你把真实感受说出来的 skill。

大多数 AI 的习惯是：你问什么，它答什么。哪怕你自己都没说清楚，它也先递一个看起来相关的方案给你。

这个 skill 反过来。它会盯着你话里对不上的地方——你说"还好"，但处境明明不好；你说"他很看重我"，但绩效给了 B——然后一次只问一个问题，陪你看见你自己没注意到的东西。

每次对话结束前，它一定会做一件事：确保你站着离开，而不是悬着离开。

## 它适合

- 职场处境、合伙关系、团队管理、创业决策里的纠结
- "我也说不清哪里不对"的那种卡住
- 想找人说说，但还不想找人说的时候

## 它不做

- 不替你做决定
- 不做心理咨询，不碰原生家庭和深层创伤
- 不给人生建议

## 使用前请读

- 它适合日常的纠结和卡住：想理一理、想找人说说。
- 如果你正处在严重的情绪困扰中——长时间失眠、情绪难以控制、有伤害自己的念头——请先联系身边信任的人，或当地的专业心理援助渠道。这个 skill 不能替代专业帮助。
- 它会追问你话里对不上的地方，有时候会碰到你还没准备好面对的东西。任何时候觉得不舒服，直接说"停"就可以。
- 推荐在 Claude 等理解能力较强的模型上使用，原因见下一节。

## 为什么对模型有要求

这不是在推荐某个产品，是这套规则本身对执行者的理解力有要求。

规则里风险最高的一步是「戳破」——把对方自己还没说出口的东西点明。它之所以安全，靠的是紧接着的落地协议被完整执行：先接住，再正常化，把选择权还给他，最后给一个能做的小动作。**戳破和落地是一件事的两半，只做前半段就是伤害。**

理解力不够的模型，典型的失手有三种：

1. **只执行前半段。** 矛盾点得又准又硬，然后就停在那儿了。对方被打开，没人接住。
2. **误判。** 把正常的表达当成矛盾，追着一个不存在的东西反复问，对方只会觉得莫名其妙地被怀疑。
3. **越界。** 规则写明不挖原生家庭和深层信念，但弱模型容易顺着话头一路往下钻——那是心理咨询的范围，不是这套方法能处理的。

另外，判断「力度超标还是偏低」需要在整段对话里比对情绪词和处境。上下文一掉，判断就是乱的。
